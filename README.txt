网页模式：
npm start

Windows 桌面悬浮窗：
双击“桌面悬浮窗.vbs”，或运行 npm run desktop

操作：
- 拖动白底灰色三横杠可移动悬浮按钮
- 单击按钮从屏幕右侧展开/收起仪表盘
- 按 Esc 收起
- 托盘图标可展开、重新加载或退出

每日阅读（桌面模式）：
- 日常待办中随机推荐文章，默认每天 4 篇，可来自同一子文件夹。
- 右上角设置可分别修改一次推荐篇数、每日目标篇数（均默认 4），以及读完判定秒数和文章目录。
- 点击文章在面板内阅读，默认前台累计 30 秒后自动勾选划线，90 天内不再推荐。
- 点击 ☆ 收藏，会给原文件名前加 ⭐，收藏与已读记录相互独立。
- “刷新推送”重新扫描目录并更换文章列表；目录也会自动检查，适应文章增删和移动。
- 每日默认读完 4 篇才完成任务（跟随每日目标篇数），可跨多批推送累计，刷新不清零，同篇不重复计数。标题下只显示“今日已完成 X/Y 篇”。
- 更新后重启桌面应用与网页服务以加载新功能。

项目结构、功能约定和验证方式见 PROJECT.md。
